# PROJECT EDGEWORTH for Board Game Arena

自作ボードゲーム **PROJECT EDGEWORTH（プロジェクト・エッジワース）** を [Board Game Arena](https://boardgamearena.com/)（BGA）に実装するためのリポジトリです。

> 現在のステータス: **立ち上げ段階**（仕様書の作成から着手します。実装コードはまだありません）

## ゲーム概要

| 項目 | 内容 |
| --- | --- |
| プレイ人数 | 2〜4 人 |
| プレイ時間 | 40〜60 分 |
| 複雑度 | 2.8 / 5 |
| ジャンル | 通信衛星網構築（同時アクション選択・相乗り・六角形の盤面） |
| 制作・著作 | だんじり協奏曲（ぞね、まや、ひのき、たづくり） |
| 公式ページ | <https://danjiri-concerto.github.io/project-edgeworth/> |

プレイヤーは国際機関 OCC に選ばれた組織の指揮官となり、衛星にプロジェクトカード（CREW / DEVICE / SOFTWARE）を配備し、打ち上げ、地球を周回させながら各地の区域で通信確立を重ねます。

- **計画フェイズ**: 全員が 5 枚のアクションカード（予算発行・配備・打ち上げ / 転回・通信確立・企画）から 1 枚を伏せて選び、一斉に公開する
- **アクションフェイズ**: 誰かが選んだアクションだけを I〜V の順に全員が実行する。選んだプレイヤーはアクション選択ボーナスを得る
- **循環フェイズ**: 稼働中の衛星が向きに沿って 1 区域進み、燃料を消費する。ニアミスで燃料を余分に失い、燃料切れで着陸 / 着水する
- 誰かの衛星 5 機が全て稼働中になるか、通信確立のキューブ 16 個を置き切ったラウンドで終了し、名声の合計が最も高いプレイヤーが勝利

ルールの一次情報は `data/rulebooks/`（ルールブックのページ画像）、[FAQ](https://danjiri-concerto.github.io/project-edgeworth/faq.html)、[エラッタ](https://danjiri-concerto.github.io/project-edgeworth/errata.html) です。

## リポジトリ構成

```text
.
├── README.md          # このファイル
├── CLAUDE.md          # Claude Code 向けの開発ルール
├── data/              # 原本アセット（作者の手元だけ。Git 管理外・公開リポジトリには無い）
│   ├── boards/        #   地域ボード・区域・トラック
│   ├── box/           #   箱絵
│   ├── cards/         #   カード画像（プロジェクト・衛星・ミッション・褒賞・アクション）
│   ├── icons/         #   地域アイコン
│   ├── piecies/       #   コマ
│   └── rulebooks/     #   ルールブックのページ画像
├── docs/              # 開発用ドキュメント
│   ├── specs/         #   仕様書（実装前に必ず作成）
│   ├── development/   #   開発ルール（Git 運用・タスクの進め方・作者への質問・FAQ の起票）
│   ├── publishing/    #   BGG・BGA の紹介文
│   └── tasks.md       #   タスク一覧（作者の作業を含む）
├── src/               # BGA Studio のプロジェクトに同期するゲーム本体（今後作成）
└── .worktrees/        # タスクごとの作業用ワークツリー（Git 管理外）
```

## 開発の進め方

1. タスクごとに `.worktrees/` 配下へワークツリーを作成する
2. まず `docs/specs/` に仕様書を作成し、PR でレビューする
3. 仕様書のマージ後、別 PR で実装する
4. PR マージ後、ワークツリーとリモートブランチを削除する

詳細は [docs/README.md](docs/README.md) を参照してください。
